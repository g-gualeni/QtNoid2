# QtNoid::App::Parameter Basic Usage
This is a simple Qt application that showcases how to use the QtNoid::App::Parameter class from QtNoidApp library for managing application parameters.

## Building

This example uses CMake for building. Ensure you have:
- Qt 6.x installed
- QtNoidApp library available
- QtNoidCommon library available

## Usage

Build and run the application to see the Parameter features in action.
