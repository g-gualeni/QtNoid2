# JsonTxt2JsonBasicUsage

## Overview

This example demonstrates the basic usage of QtNoidJson Txt2Json conversion features.

## Description

JsonTxt2JsonBasicUsage provides a simple Qt application that showcases how to use the Txt2Json functionality from QtNoidJson library for converting text-based formats to JSON.

## Building

This example uses CMake for building. Ensure you have:
- Qt 6.x installed
- QtNoidJson library available
- QtNoidCommon library available

## Usage

Build and run the application to see the Txt2Json conversion features in action.
