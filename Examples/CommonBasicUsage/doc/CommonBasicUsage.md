# CommonBasicUsage

## Overview

This example demonstrates the basic usage of QtNoidCommon library features.

## Description

CommonBasicUsage provides a simple Qt application that showcases the fundamental capabilities of the QtNoidCommon library.

## Building

This example uses CMake for building. Ensure you have:
- Qt 6.x installed
- QtNoidCommon library available

## Usage

Build and run the application to see the QtNoidCommon features in action.
