# QtNoidCommon
This module contains:
- **[[File]]**: collection of methods to list and manage files, rename, read and write text files. 
- **[[Scale]]**: convert numbers to a human readable format.
- **[[Text]]**: clean up, tokenize convert to camel case or snake case methods.

&nbsp;

## CMake
```
find_package: QtNoidCommon

target_link_libraries: QtNoid::QtNoidCommon
```

&nbsp;

## Header

```cpp
#include "QtNoidCommon/QtNoidCommon"
```

&nbsp;

## Namespace

```cpp
using namespace QtNoid::Common;
```
