# Class: Yaml2Json
This class parses a YAML text and converts it into a `QJsonDocument`. The basic application is to help humans generate JSON files using YAML, which is more readable, less redundant and faster to write. The conversion is performed automatically every time the YAML text is set, either through the constructor or through `setYaml()`, so the result is immediately available with `json()`, `jsonArray()`, `document()` or `jsonAsString()`.

The YAML parsing is done by [rapidyaml](https://github.com/biojppm/rapidyaml) (MIT license):

```
YAML Text → [rapidyaml] → JSON text → [QJsonDocument::fromJson] → QJsonDocument
```

- Anchors and aliases (`&name` / `*name`) are resolved before the conversion.
- For a multi-document stream (`---`), only the first document is converted.
- The root node must be a map (converted into a `QJsonObject`) or a sequence (converted into a `QJsonArray`). A plain scalar as root is reported as an error. An empty text gives an empty `QJsonObject`.
- Scalars follow YAML 1.2 rules: `true`/`false` are Booleans, `null` is null, numbers are numbers, everything else (including `yes`, `no`, `~`) is a string.

## CMake dependency
rapidyaml is downloaded by `FetchContent` (tag `v0.16.0`) at configure time, built as a static library and linked `PRIVATE` into QtNoidJson. It is not installed and it is not visible to the users of QtNoidJson. The first configure needs network access to github.com.

## Static Methods
- `QJsonDocument convert(const QString &yaml, QString *error = nullptr)`: Converts the YAML text and returns the resulting document. In case of error returns a null `QJsonDocument` and, if `error` is not null, fills it with the error description. This can be used for a one-shot conversion, without creating an object.

## Constructors
- `Yaml2Json(QObject *parent = nullptr)`: Creates an empty converter. Use `setYaml()` to provide the text to convert.

- `Yaml2Json(const QString &yaml, QObject *parent = nullptr)`: Creates a converter and immediately converts the given YAML text. Check `isValid()` to know if the conversion succeeded.

## Destructors
- `~Yaml2Json()`: Default destructor.

## YAML management methods
- `yaml()`: Returns the current YAML text.
- `setYaml(const QString &newYaml)`: Sets the YAML text and triggers the conversion. If the text is the same as the current one, nothing happens and the previous result is kept.

## Result methods
- `isValid()`: Returns true if the last conversion succeeded.
- `errorString()`: Returns the error description of the last conversion, or an empty string if the conversion succeeded. Parse errors include the position in the YAML text, for example `YAML error at line 2, column 1: parse error`.
- `document()`: Returns the `QJsonDocument` generated by the last conversion. It can contain an object or an array. In case of error a null document is returned.
- `json()`: Returns the root `QJsonObject`. Empty if the conversion failed or if the root is a sequence.
- `jsonArray()`: Returns the root `QJsonArray`. Empty if the conversion failed or if the root is a map.
- `jsonAsString(QJsonDocument::JsonFormat format = QJsonDocument::Indented)`: Returns the generated JSON as a string, indented by default, or compact with `QJsonDocument::Compact`. Returns an empty string in case of error.

## Signals
- `errorOccurred(const QString& error)`: Emitted when a conversion fails, with the same text returned by `errorString()`.

## Example
```cpp
#include "QtNoidJson/QtNoidJson"
using namespace QtNoid::Json;

Yaml2Json converter(yamlText);
if (converter.isValid()) {
    QJsonObject obj = converter.json();
    qDebug().noquote() << converter.jsonAsString();
} else {
    qWarning() << converter.errorString();
}

// One shot conversion
QString error;
QJsonDocument doc = Yaml2Json::convert(yamlText, &error);
```

This is an example of YAML text accepted by the converter:
```yaml
person:
    name: "Mario Rossi"
    age: 30
    active: true
    email: mario.rossi@example.com
    address:
        city: Milano
        cap: 20100
        street: "Via Roma 123"
    hobbies: [calcio, cucina, lettura]
    tags: ["tag con spazi", semplice, altro]
    social:
        platforms: [facebook, twitter, linkedin, instagram]
        followers: [1500, 2300, 890, 4200]
    contacts:
        - name: "Luca Bianchi"
          phone: "333-1234567"
          email: luca@example.com
        - name: "Anna Verdi"
          phone: "347-7654321"
          email: anna@example.com
```

## Implementation notes
- In `yaml2json.cpp` the rapidyaml headers must be included **before** any Qt header, because Qt defines `emit` as a macro and that breaks the `ryml::emit*()` functions.
- rapidyaml's default error handlers print to stderr. QtNoidJson replaces them, once, with handlers that only throw, so the message is reported through `errorString()`. The handlers are global for rapidyaml, but rapidyaml is private to QtNoidJson.
